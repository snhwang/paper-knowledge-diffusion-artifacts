# Topic Source Papers

Each panel-discussion session in `bear_parlor/session_logs/` was seeded with
a small set of research papers on a specific biomedical topic. The PDFs
themselves are **not redistributed here** (third-party copyright). This file
indexes the source papers per topic so the panel inputs can be retrieved
independently.

Session-log filenames follow `brainstorming-hats_YYYYMMDD_HHMMSS.md`. The
mapping from filename to topic lives in the eval scripts
(`evals/eval_*.py`) — search for `TOPIC_ORDER` or the per-file topic dicts.

> Where a DOI is not listed, substitute the publisher URL or PubMed ID.
> Filenames below reflect the original PDF names used during the study.
