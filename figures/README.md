# Figure generation

Every graphic in the manuscript is either generated by a script in this
repository or drawn in the LaTeX source itself. Nothing is hand-made in an
external editor.

| Manuscript figure | Produced by | Output file | Copied to the paper as |
|---|---|---|---|
| Figure 1, motivation worked example | none — TikZ in `main_exsy.tex` | — | — |
| Figure 2, BEAR retrieval pipeline | `figures/gen_pipeline_figure.py` | `figures/bear_pipeline.pdf` | `figures/bear_pipeline.pdf` |
| Figure 3, YAML instruction | none — `lstlisting` in `main_exsy.tex` | — | — |
| Figure 4, session excerpt | none — quoted from a session log | — | — |
| Figure 5, temporal evolution | `evals/eval_temporal_reconciled.py` | `evals/results/temporal_reconciled.pdf` | `figures/temporal_evolution.pdf` |
| Figure 6, knowledge flow matrix | `evals/eval_knowledge_flow_matrix.py` | `evals/results/knowledge_flow_matrix.pdf` | `figures/knowledge_flow_matrix.pdf` |

**Note the rename.** The temporal figure is written as
`temporal_reconciled.pdf` and enters the manuscript as
`temporal_evolution.pdf`. The copy is manual, so a regenerated figure does not
reach the paper until it is copied across:

```bash
cp evals/results/temporal_reconciled.pdf   <paper>/figures/temporal_evolution.pdf
cp evals/results/knowledge_flow_matrix.pdf <paper>/figures/knowledge_flow_matrix.pdf
python figures/gen_pipeline_figure.py && cp figures/bear_pipeline.pdf <paper>/figures/
```

The pipeline script depends only on matplotlib. The two eval scripts embed
session text, so they need `sentence-transformers` and the model named in
`requirements.txt`; see [`../RUNNING_EXPERIMENTS.md`](../RUNNING_EXPERIMENTS.md).
