# Dependencies for reproducing the knowledge-diffusion paper's results.
#
#   python -m venv .venv
#   source .venv/bin/activate        # .venv\Scripts\activate on Windows
#   pip install -r requirements.txt
#
# The session-log analyses (evals/) need only numpy, scipy, matplotlib and
# sentence-transformers. The benchmark harnesses (benchmarks/) additionally
# need openai and python-dotenv for API access, and bear is required only by
# eval_embed_only_baseline.py, which imports bear.retriever.Embedder.

# --- BEAR, pinned to the version that generated the sessions ---------------
# The sessions in bear_parlor/session_logs/ were produced with v0.1.0
# (commit 515366e). Later releases changed retrieval over-fetch behaviour under
# hard gating, so a newer version need not reproduce the published numbers.
# The eval scripts read recorded logs and store snapshots, so they do not
# themselves depend on this pin.
# The v6 sessions (bear_parlor/session_logs/v6/) did NOT use this pin: the Parlor
# server imports BEAR from the bear-dev checkout, commit d90058c. See
# EXPERIMENT_LOG.md, v6.
bear @ git+https://github.com/snhwang/bear.git@v0.1.0

# --- NOT a pip dependency: Mathpix -----------------------------------------
# Regenerating panel sessions from the source PDFs also needs a Mathpix OCR
# account (MATHPIX_APP_ID / MATHPIX_APP_KEY). Every reported session used it.
# Without those variables, ingestion falls back to pypdf silently and retains
# roughly a quarter as much text per document. Nothing in evals/ needs it.
# See RUNNING_EXPERIMENTS.md section 2.

# --- embeddings ------------------------------------------------------------
# Required by every eval that embeds text. All results use
# BAAI/bge-base-en-v1.5 (768-dim), downloaded automatically on first run.
sentence-transformers>=3.0

# --- numerics, statistics, plotting ----------------------------------------
numpy>=1.24
scipy>=1.10
matplotlib>=3.7

# --- configuration and benchmark harnesses ---------------------------------
PyYAML
python-dotenv
openai

# --- generating panel sessions (bear_parlor/run_sessions.py) ----------------
# Not needed to analyse recorded sessions. Needs Python 3.10-3.13: ChromaDB
# does not import under 3.14. Exact tested versions are recorded in
# bear_parlor/requirements-sessions.lock.txt. The Parlor server imports BEAR
# from the bear-dev checkout it runs from, ahead of the pinned package above.
# Mathpix credentials (MATHPIX_APP_ID, MATHPIX_APP_KEY) go in bear-dev's .env.
aiohttp>=3.9                  # session runner
fastapi>=0.104.0              # Parlor server
uvicorn[standard]>=0.24.0
websockets>=12.0
python-multipart>=0.0.9       # PDF upload endpoint
chromadb>=0.4.0               # per-hat knowledge stores
pypdf>=4.0.0                  # fallback PDF extraction
requests>=2.28                # Mathpix API

anthropic>=0.20.0             # only for Anthropic models
